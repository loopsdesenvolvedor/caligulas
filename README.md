# Caligula's
A fullstck adult plataform build with Javascript.
---

## About the Platform
<strong>Caligula's</strong> is a platform intended exclusively for users aged 18 and over. 
The project aims to provide a complete adult entertainment experience by bringing 
different types of content together in a single platform.

- Video streaming for adult audiences;
- A blog featuring erotic stories;
- A catalog of content creators integrated through an external API;
- A modern, intuitive, and responsive interface designed to provide the best user experience.
